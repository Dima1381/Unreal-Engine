🚧 Obstacle Assault

**Obstacle Assault** is a small obstacle-based game built with **Unreal Engine**.  
The player must navigate through moving and rotating platforms to reach the goal.

---

#🛠️ Core Features

- 📦 Moving platforms
- ⚙️ Configurable platform movement
- 🔄 Rotating platforms
- 🏗️ Simple level design focused on movement

---

🎯 Project Focus
- Platform movement logic
- Transform updates (location & rotation)
- Creating dynamic obstacles
