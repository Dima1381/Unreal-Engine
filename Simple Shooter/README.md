# 🔫 Simple Shooter

**Simple Shooter** is a first-person shooter project developed using **Unreal Engine**.  
The goal of this project is to build a complete FPS gameplay loop, including combat, enemy AI, animations, sound, UI, and level design.

---

## 🛠️ Action Plan

1️⃣ Project, Assets & Test Level Setup
- Created a new Unreal Engine project with FPS settings.
- Imported required assets (meshes, animations, sounds).
- Built a test level to validate core gameplay mechanics.

---

2️⃣ Character Animations
- Implemented first-person character animations.
- Added animation states for:
  - Idle
  - Movement
  - Shooting
  - Death
- Ensured smooth transitions between animations.

---

3️⃣ Guns and Shooting
- Designed a weapon system for the player.
- Implemented:
  - Gun mesh attachment to the character
  - Shooting logic
  - Line trace / projectile-based shooting
- Added firing effects and recoil feedback.

---

4️⃣ Damage and Death System
- Implemented a health system for player and enemies.
- Damage is applied when a target is hit.
- When health reaches zero:
  - Death animation is triggered
  - Actor is destroyed or disabled

---

5️⃣ Enemy AI with Behavior Trees
- Created enemy AI characters.
- Implemented artificial intelligence using **Behavior Trees**:
  - Patrol behavior
  - Player detection
  - Chasing and attacking
- AI reacts dynamically to player actions.

---

6️⃣ Sounds, Particles & HUD UI
- Added sound effects for:
  - Gunshots
  - Hits
  - Death
- Implemented particle effects for shooting and impacts.
- Created a HUD UI displaying:
  - Player health
  - Crosshair
  - Game feedback elements

---

7️⃣ Level Design
- Designed a playable level with:
  - Strategic enemy placement
  - Cover and open combat areas
  - Clear navigation paths
- Balanced gameplay for challenge and fun.

---

🚀 Project Goals
- Learn FPS game development fundamentals.
- Practice:
  - Weapon systems
  - Enemy AI with Behavior Trees
  - Damage handling
  - UI and audio integration
- Build a complete and playable shooter prototype.

---

📌 Notes
- This project is developed for learning purposes.
- Can be extended with additional weapons, enemies, or levels.

---

🔫 **Enjoy the fight!**
