🏗️ Warehouse Wreckage

**Warehouse Wreckage** is a small physics-based game developed with **Unreal Engine**.  
The player uses limited ammo to shoot projectiles and destroy objects inside a warehouse.

---

🛠️ Core Features

- ⚙️ Physics-based gameplay
- 💣 Spawning and firing projectiles
- 🎯 Aiming system for accurate shots
- 🏗️ Simple warehouse level design
- 🔫 Limited ammo system
- 🔄 Level reload when ammo is depleted

---

🎯 Project Focus
- Working with physics and collisions
- Projectile mechanics and aiming
- Level building and gameplay limits
